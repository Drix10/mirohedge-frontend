# MiroHedge Website: Landing Page for an AI-Assisted Hedge Fund

Source for **[mirohedge.com](https://www.mirohedge.com)**, the public site of MiroHedge: a research lab working to bring hedge-fund discipline to everyone, with AI that has to prove itself before it is trusted with a single dollar.

[![Website](https://img.shields.io/badge/mirohedge.com-live-111111?style=for-the-badge)](https://www.mirohedge.com)
[![Research repo](https://img.shields.io/badge/research-hypothesis--arena-informational?style=for-the-badge&logo=github)](https://github.com/Drix10/hypothesis-arena)

## About MiroHedge

MiroHedge is an AI-assisted systematic fund that trades the slow spread of news between linked firms. Models read; deterministic code sizes, risks and executes every trade. The research, C++17 kernel and backtesting harness live in **[Drix10/hypothesis-arena](https://github.com/Drix10/hypothesis-arena)**. Paper trading only.

## Tech

- Plain **HTML, CSS and JavaScript**, no build step
- `orb.js`: the animated 3D wireframe orb in the hero
- `sections.css`, `styles.css`, `fonts.css`: layout, typography and section styles

## Run locally

```bash
git clone https://github.com/Drix10/mirohedge-frontend.git
cd mirohedge-frontend
npx serve .   # or open index.html in a browser
```
